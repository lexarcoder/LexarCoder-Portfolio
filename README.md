## ⚙️ Installation & Setup

### 📦 Requirements

* Node.js `18+`
* MongoDB
* Git
* API credentials for required services

### 1. Clone Repository

```bash
git clone https://github.com/lexarcoder/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies

Install dependencies separately for the **frontend** and **backend**.

#### 🎨 Frontend

```bash
cd frontend
npm install
```

#### ⚙️ Backend

Open a **new terminal** and run:

```bash
cd backend
npm install
```

### 3. Environment Variables

Create a `.env` file inside the `backend` directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret

GEMINI_API_KEY=your_gemini_api_key

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_secret

MAIL_USER=your_email
MAIL_PASSWORD=your_email_app_password
```

### 4. Run Development Servers

Run the **frontend** and **backend** in separate terminals.

#### 🎨 Frontend

```bash
cd frontend
npm run dev
```

#### ⚙️ Backend

```bash
cd backend
npm run dev
```

> 💡 Keep both terminals running while developing the application.

The frontend runs using the Vite development server, while the backend uses **Nodemon** for automatic server restarts.

### 🔐 Security

Never commit your `.env` file or sensitive credentials to GitHub.

Add the following to `.gitignore`:

```gitignore
.env
node_modules/
```
